# 📊 Аналітика особистих витрат monobank

Пет-проєкт з аналізу даних: я вивантажила власну виписку через відкритий API monobank, проаналізувала структуру й динаміку витрат у pandas, знайшла типи покупок за допомогою ML-кластеризації та зробила веб-дашборд.

**🔗 Дашборд:** https://nisachunda-rgb.github.io/mono-spending-analytics/

## Що зроблено

1. **Збір даних** — `fetch_statement.py`: скрипт вивантажує транзакції через [monobank API](https://api.monobank.ua/docs/) з урахуванням обмежень API (1 запит на 60 с, вікно ≤ 31 доба, до 500 транзакцій у відповіді).
2. **Аналіз** — `analysis.ipynb` (pandas, matplotlib):
   - категоризація покупок за MCC-кодами;
   - структура витрат, динаміка по місяцях, активність за днями тижня й годинами;
   - топ місць покупок.
3. **SQL** — `sql_analysis.ipynb` (SQLite): ті самі дані в базі, відповіді SQL-запитами — `JOIN` з довідником MCC-категорій, `VIEW`, `CASE`, CTE, підзапити, віконні функції (`SUM() OVER`, `ROW_NUMBER() OVER (PARTITION BY ...)`): частки категорій, індекс по місяцях, топ-3 категорії в кожному місяці, накопичувальна частка. Результати звірено з pandas.
4. **ML** — кластеризація покупок методом **KMeans** (scikit-learn) за розміром чека, часом доби та днем тижня; кількість кластерів обрано за silhouette score.
5. **Дашборд** — `docs/index.html` (HTML/CSS/JS, Chart.js), опублікований через GitHub Pages.

## Ключові висновки

- Найбільші категорії — **краса (~32%)** і **продукти (~22%)**: разом понад половину витрат.
- Пік активності — **субота** (23% покупок) і **16–17 година**.
- Модель виділила **4 типи покупок**; головний — покупки в будні близько 16:00 (60% витрат).
- З серпня витрати по картці майже зникли через переїзд до Польщі — дані покривають лише один рахунок, для повної картини треба об'єднувати джерела.

## 🔒 Приватність

Реальні транзакції (`transactions.csv`, база `mono.db`) не публікуються — файл у `.gitignore`. Ноутбук у режимі `PUBLIC = True` і дашборд показують лише частки (%) та індекси, без сум і назв магазинів.

## Як запустити

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install requests pandas matplotlib scikit-learn ipykernel

export MONO_TOKEN="your_token"        # токен з https://api.monobank.ua
python3 fetch_statement.py --months 6  # → transactions.csv
# далі відкрити analysis.ipynb і виконати Run All → docs/data.js
# SQL-частина: sql_analysis.ipynb → Run All
```
